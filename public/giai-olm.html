📲 Tiện ích xem đáp án trên Safari iOS

Dùng chung 1 Key với Tool tự động giải. Key khóa cố định theo tài khoản OLM và thiết bị (HWID) để chống dùng ké.

Bước 1 · Tải app Userscripts: Lên App Store tải ứng dụng miễn phí Userscripts (biểu tượng </>).
Bước 2 · Tải file tiện ích: Bấm nút tải bên dưới → Lưu vào Tệp → mở app Userscripts chọn Set Userscripts Directory tới thư mục chứa file olm_helper.user.js.
Bước 3 · Bật trong Safari: Vào Cài đặt → Safari → Phần mở rộng → Userscripts (Bật). Sau đó mở olm.vn bằng Safari → bấm chữ aA / mảnh ghép góc trái thanh địa chỉ → chọn Userscripts → Luôn cho phép trên trang web này.
Bước 4 · Nhập Key: Trên trang bài tập OLM, bấm nút 💡 nổi → nhập mã Key (OLM-...) → bấm Kích hoạt & Lưu máy để xem toàn bộ đáp án.
