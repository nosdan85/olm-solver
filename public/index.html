TIỆN ÍCH SAFARI iOS

Hướng dẫn cài & dùng Userscript trên iPhone / iPad

Xem trực tiếp đáp án mọi dạng câu hỏi trên olm.vn bằng Safari iOS. Dùng chung 1 mã Key với Tool giải tự động.

📥 Tải file olm_helper.user.js ↓
  1. 01
    Cài app Userscripts trên App Store

    Mở App Store trên iPhone/iPad, tìm và tải ứng dụng miễn phí Userscripts (biểu tượng chữ </> của Justin Wasack).

  2. 02
    Tải file olm_helper.user.js vào thư mục Userscripts

    Bấm nút Tải file olm_helper.user.js ở trên → chọn Lưu vào Tệp (Save to Files) → lưu vào thư mục riêng (ví dụ iCloud Drive/Userscripts hoặc Trên iPhone/Userscripts). Sau đó mở app Userscripts → bấm Set Userscripts Directory → chọn đúng thư mục vừa lưu.

  3. 03
    Bật tiện ích & cấp quyền cho Safari

    Vào Cài đặt iPhone → Safari → Phần mở rộng (Extensions) → Userscripts và bật Cho phép Phần mở rộng. Tiếp theo vào trang https://olm.vn trên Safari → bấm biểu tượng aA / mảnh ghép ở góc trái thanh địa chỉ → chọn Userscripts → chọn Luôn cho phép trên trang web này (Always Allow on This Website).

  4. 04
    Nhập Key kích hoạt ngay trên trang OLM

    Đăng nhập tài khoản OLM của bạn trên Safari, mở một bài tập bất kỳ → bấm nút tròn 💡 nổi ở góc màn hình → nhập mã Key (OLM-...) → bấm Kích hoạt & Lưu máy để sử dụng tiện ích xem đáp án.
